2026-09-11: WS01 SMB share exposure validation and remediation

Windows permissions:
| Code | Meaning           | Plain explanation                                                          |
| ---- | ----------------- | -------------------------------------------------------------------------- |
| `I`  | Inherited         | This permission came from the parent folder.                               |
| `OI` | Object inherit    | Files inside inherit this permission.                                      |
| `CI` | Container inherit | Subfolders inherit this permission.                                        |
| `IO` | Inherit only      | Applies to contents, **not the folder carrying this rule**.                |
| `F`  | Full control      | Read, change, delete, and manage permissions.                              |
| `RX` | Read and execute  | Read files, run programs, and move through folders.                        |
| `M`  | Modify            | Read, change, and delete files, without full permission-management rights. |

replace/set explicit allow permissions for these accounts/groups:
```WS01

processed file: C:\LabShares\PSL-Support-Private
Successfully processed 1 files; Failed processing 0 files
```
notice how `PSL\Domain Users` has `Read and Execute (RX)` permissions, it shouldn't have that. This includes `kbennett` who is outside `GG-PSL-User-Support`.
this is the deliberate mistake: an ordinary employee can read a file intended for support staff.
later, this will be removed and verify that `kbennett` is blocked while `benjamin-admin` can still read it.
