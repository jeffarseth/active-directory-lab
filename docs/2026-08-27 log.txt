2026-08-27: Account lockout policy and delegated unlock validation

vmware stale lock recovery:
when starting `DC01`, vmware reported that the virtual machine was in use by another computer and that ownership recovery had failed.
i ended the remaining `vmware.exe` process using task manager, opened the virtual machine directory containing `DC01.vmx`, and removed the stale `.lck` files. after relaunching vmware, `DC01` started normally.

read the current domain lockout policy:
```
PS C:\Users\Administrator> Get-ADDefaultDomainPasswordPolicy -Identity "ad.pearsonspecterlitt.com" | Select-Object LockoutThreshold,LockoutDuration,LockoutObservationWindow | Format-List


LockoutThreshold         : 0
LockoutDuration          : 00:10:00
LockoutObservationWindow : 00:10:00
```
these values show whether automatic account lockout is enabled, how long a lockout lasts, and when the failed-attempt counter resets. `LockoutThreshold` 0 means automatic lockout is currently disabled.
